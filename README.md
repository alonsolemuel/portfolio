# Lemuel Alonso – Portfolio

My personal portfolio: projects, startup idea, skills, resume and contact.

Built with plain HTML, CSS and JavaScript (no frameworks). Deployed on Vercel.

## Edit content

Projects, skills and social links are at the top of the `<script>` in `index.html`:
`PROJECTS`, `OTHER`, `SKILLS`, `SOCIALS`.

- Profile photo: `assets/profile.jpg`
- Project screenshots: `assets/projects/`
- Resume: `Lemuel-Alonso-Resume.pdf`
